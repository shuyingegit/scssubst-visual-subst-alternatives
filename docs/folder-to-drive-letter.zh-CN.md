# 「把文件夹映射成盘符」的完整选型（场景版 · 中文）

官网：<https://subst.scsoi.com/>

搜「文件夹映射盘符」的人，问的通常不是命令本身，而是三个具体麻烦：

1. **重启后盘符没了** —— 原生 `subst` 只是会话级映射，注销或重启即失，要自己写 bat / 任务计划重建；
2. **提权程序看不见这个盘** —— 盘符映射属于创建它的那个会话，普通会话里建的映射在提权（管理员）会话里看不到，反之亦然；
3. **老软件 / 安装程序不认 subst 盘** —— 部分老程序只认真正的卷，不认 subst 映射出来的盘。

## 常见问题

**Q: 文件夹映射盘符，重启后怎么让它还在？**
A: 原生 `subst` 是会话级映射，注销或重启就没了，只能自己写 bat 丢进启动项或建登录任务。ScsSubst 保存映射清单、**在应用启动时重新挂载，注销和重启之后盘符会回来**，而且挂载**不需要管理员权限**：<https://subst.scsoi.com/>

**Q: subst 映射的盘符，管理员程序为什么看不到？**
A: 因为盘符映射属于创建它的那个会话：在普通会话里建立的映射，在提权（管理员）会话里看不到，反之亦然。ScsSubst 提供一个**高级选项让映射对提权程序可见**，所以你以管理员身份跑的程序能打开同一个盘符；而 Session 0 的服务仍然看不到——这类工作要跑在交互式会话里、用拥有映射的那个用户来跑。官网：https://subst.scsoi.com
